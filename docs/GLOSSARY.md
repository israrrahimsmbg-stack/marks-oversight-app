# Glossary

| Term | Meaning |
|---|---|
| **RAG** | Red / Amber / Green status. Red = out of date or not done; Amber = coming due or slightly late; Green = in date. Plus **Not recorded** and **N/A**. |
| **Forward look** | What becomes due in the next 7, 14, 30 and 90 days. |
| **Drill-down** | Clicking a headline number to see the items, owner and next action behind it. |
| **Owner / next action** | The named person responsible for an item, and the dated next step they will take. |
| **Escalation** | Telling the next level up when an item stays overdue: service manager, then Mark and Hamida. |
| **Tracker** | A recurring check or record kept per service (fire log, fire exits, medication audit, certificates, occupancy, QA audit, etc.). |
| **Service / house / home** | One Esto Care location. |
| **Service manager, deputy, team leader** | Service-level roles who own day-to-day compliance. |
| **Support worker** | Front-line staff. May complete checks; never receives escalations. |
| **Head office** | Mark, Hamida, Yasmin and leadership. Last resort for escalation. |
| **Operations app** | Esto Care Operations app (Phase 0): homes, rooms, voids, income lost, compliance, reports. |
| **PCS** | The electronic care and medication record system (probably Person Centred Software [TBC]). Medication and resident records live there, not in our apps. |
| **QA audit** | Hamida's internal quality assurance audit per service, with actions. |
| **The Grange** | The service whose new trackers are the model for every house. |
| **Void** | An empty room/flat available to let; lost income. |
| **CQC** | Care Quality Commission: regulator of regulated activities (e.g. personal care) in England. |
| **KLOE** | Key line of enquiry: CQC's new framework headings (replacing quality statements, 2026). |
| **Reg 17** | CQC Regulation 17, Good governance: audit, oversight, records. The legal hook for this whole app. |
| **FSO** | Regulatory Reform (Fire Safety) Order 2005. |
| **Responsible person** | The person/organisation with fire safety duties for premises under the FSO. |
| **FRA** | Fire risk assessment. |
| **CP12** | Landlord gas safety record (annual). |
| **EICR** | Electrical installation condition report (usually 5-yearly). |
| **EPC** | Energy Performance Certificate (valid 10 years). |
| **PAT** | Portable appliance testing. |
| **L8 / HSG274** | HSE guidance on controlling legionella in water systems. |
| **LOLER** | Lifting Operations and Lifting Equipment Regs 1998 (hoists: 6-monthly examination). |
| **DoLS / LPS** | Deprivation of Liberty Safeguards / Liberty Protection Safeguards (LPS not yet in force). |
| **s117** | Mental Health Act s117 aftercare: free aftercare jointly funded by council and ICB. |
| **PAMMS** | Council quality assessment tool for commissioned care. |
| **Exempt accommodation** | Supported housing where Housing Benefit covers higher rent because care, support or supervision is provided. |
| **SHROA** | Supported Housing (Regulatory Oversight) Act 2023: local licensing and national standards (being set up). |
| **DPIA** | Data protection impact assessment, required before high-risk processing under UK GDPR. |
| **DSPT** | NHS Data Security and Protection Toolkit (annual self-assessment). |
| **ADR** | Architecture decision record (`docs/DECISIONS.md`). |
| **BRD** | Business requirements document (`docs/BRD.md`). |
